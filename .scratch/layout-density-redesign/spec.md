# 桌面工作区排版重设计

## 目标

- 让正式页面在桌面宽屏上使用更多可用横向空间，消除标签流程左右大片空白。
- 保留三步工作流、章节单开、项目抽屉、实时简报和现有 API/数据合同。
- 让标签章节和选项以更高信息密度呈现，同时维持清晰的阅读层级。

## 非目标

- 不修改 Python API、SQLite 表、标签配置、生成逻辑或图片任务。
- 不迁移 React 原型，不新增前端依赖，不改变移动端固定底部操作逻辑。
- 不改变项目抽屉、自动保存、历史和采用行为。

## 验收例子

- 1280px 桌面下，工作区不再被固定在 1120px 中央窄栏，步骤流和编辑区使用安全边距内的可用宽度。
- 宽屏下第 2 步的闭合章节以两列排列；展开章节横跨编辑区整行，选项以多列网格展示。
- 右侧实时简报与主编辑区保持稳定比例，并在滚动时可继续查看。
- 390px 移动端仍为单列，无横向溢出，底部主操作和项目抽屉行为不变。

## 风险与回滚

- 风险：宽度增大后个别长标签或章节高度变化，需要通过桌面和移动视口检查文字溢出。
- 回滚：恢复本次修改的 `static/styles.css` 和本变更卡，不触碰运行数据。
