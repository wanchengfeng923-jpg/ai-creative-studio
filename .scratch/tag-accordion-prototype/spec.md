# 标签折叠流程视觉原型

## 设计问题

复杂标签配置能否同时获得向导的低认知负担、表单的自由返回能力和清单的整体进度感？

## 目标

- 用三个结构差异明显的隔离原型比较折叠式标签流程。
- 使用两份 Excel 中的真实模块名称、定义、选择规则和代表性选项。
- 展示类控件按模块语义区分：主目标/附目标、主选/辅助角色位、卖点关系过滤、风格三级级联、主体×背景动态九宫格和轮播条件模块。
- 演示未开始、当前编辑、已完成、校验错误、明确跳过和条件模块动态出现。
- 在桌面和移动端展示稳定的单模块编辑体验。

## 非目标

- 不修改正式 `static/index.html`、`static/app.js` 或 `static/styles.css`。
- 不连接真实项目、API、SQLite、自动保存或 AI 生成。
- 不修改两份 Excel 或 `config/creative_tag_options.json`。
- 不将原型代码直接提升为生产实现。

## 三个变体

- A「聚焦卡片」：居中窄列、吸顶进度、轻量卡片，最接近最终正式版候选。
- B「清单工作台」：桌面端进度摘要成为左侧检查面板，适合高频专业用户。
- C「章节轨道」：编号轨道与编辑章节形成强叙事感，强调“当前只做一件事”。

## 验收

- `?variant=A|B|C` 可切换且刷新保持。
- 默认只展开一个模块，可返回编辑已完成模块。
- “完成并继续”校验、折叠并打开下一模块。
- 可选模块可明确跳过；未处理与已跳过有不同文字和图标。
- 轮播条件模块按前置选择动态显示，进度分母同步变化。
- 1280×720 和 390×844 无页面横向溢出；移动端主操作固定在底部。

## 回滚

删除 `static/tag-flow-prototype.*` 和本变更卡；正式页面与运行数据不受影响。
