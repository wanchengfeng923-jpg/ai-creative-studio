# 权限登录与账号管理变更卡

## 目标

为 AI 创意工作台增加可扩展的账号登录和角色授权能力，支持管理员管理普通账号，并让项目、文件、历史、生成和图片资源按所有者隔离。

## 非目标

- 本次不把网页服务绑定到局域网或公网。
- 本次不配置域名、HTTPS、反向代理、防火墙、外部身份提供商或公网部署。
- 本次不接入 ERP 用户、ERP 数据库或第三方 OIDC。
- 本次不提供自助注册、用户删除、用户间项目共享或细粒度项目协作者。
- 本次不修改 AI 网关、提示词、图片任务协议和生成结果结构。

## 已确认的业务规则

- 首个管理员通过一次性 CLI 或仅在用户表为空时生效的环境变量创建。
- 历史项目全部归属首个管理员；不会自动共享给新账号。
- 管理员可以查看、编辑、删除和生成所有项目。
- 普通用户只能操作自己创建的项目和其关联资源。
- 管理员可以创建、停用/启用和重置普通账号；不提供删除账号。
- 普通用户只能修改自己的密码；重置后的账号下次登录必须改密码。
- 管理员重置密码时由服务端生成一次性临时密码，仅在成功响应中展示一次；数据库不保存明文密码。

## 验收例子

1. 未初始化时，业务 API 不可访问；`init-admin` 成功后重复执行不会覆盖账号或重复归属项目。
2. 正确密码登录后获得 HttpOnly 会话 Cookie；错误登录不泄露账号是否存在，并触发失败限流。
3. 未登录请求返回 401；普通用户访问他人项目、历史、文件或图片返回 403/统一资源错误，不泄露资源细节。
4. 所有写请求（登录除外）缺失或伪造 CSRF Token 时被拒绝。
5. 管理员创建普通账号、停用/启用账号、重置密码均可审计；停用和重置立即撤销该账号所有会话。
6. 管理员不能停用最后一个管理员，普通用户不能修改角色。
7. 现有项目、历史、图片和上传文件在迁移后保持可读取，且全部归属初始化管理员。
8. 现有生成、采用、图片轮询和重试行为在授权通过后保持不变。

## 风险与回滚

- 风险：数据库迁移、会话处理、项目 ID 越权、Cookie/CSRF 配置错误、登录暴力尝试。
- 上线前必须备份 `data/creative_studio.db`、`data/images/` 和 `data/uploads/`。
- 代码回滚以提交为边界；数据回滚先保留当前数据库，再恢复经过验证的备份，不直接覆盖运行中的数据库。
- 认证迁移失败时服务不启动业务线程，不删除或重建现有数据。

## 验证记录

实现完成后补充单元、HTTP 集成、前端静态和现有回归检查结果；真实 AI 请求、公网 HTTPS 和外部限流明确标记为未验证或另行发布。
