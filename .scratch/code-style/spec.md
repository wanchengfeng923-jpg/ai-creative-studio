# 建立代码规范文档

## 目标

在项目根目录新增可执行的 `CODE_STYLE.md`，覆盖当前正式原生前端、Python 后端和隔离 React 原型的技术栈、命名、组织、导入、注释、安全与验证规则。

## 非目标

- 不迁移前端框架或路由。
- 不引入 ESLint、Prettier、Ruff 或新的运行依赖。
- 不批量格式化已有代码。
- 不修改业务行为、数据库、AI 网关或运行数据。

## 验收

- 维护者能判断正式入口与原型的不同规则。
- 文档明确当前状态管理、样式和路由方案，而非填写理想化技术栈。
- JavaScript/TypeScript 使用 JSDoc，Python 使用文档字符串，注释解释原因与约束。
- `AGENTS.md`、README 和代码地图可发现该文档。
- Markdown 差异通过 `git diff --check`。

## 回滚

撤销本次文档提交即可；本次不修改代码、配置、依赖或运行数据。
