# 已选标签摘要与章节收起

## 目标

- 每个标签章节标题下方直接显示已选标签名称，替换原有“x 项已选”状态文案。
- 点击最后一个可见章节的“确认本章并继续”后，所有章节收起。

## 非目标

- 不修改标签配置、选择上限、主辅字段、API、数据库或生成逻辑。
- 不改变展示类和叙事类已有选项内容及条件联动。

## 验收

- 选择任意标签后，标签名称出现在对应章节标题下方；未选择时不显示数量文案。
- 章节内仍可点击选项取消选择，主选/辅助和级联逻辑正常。
- 最后一个可见章节确认后 `openKey` 为空，页面所有章节收起。
- `1280x720`、`390x844` 无横向溢出，浏览器无 error/warn。

## 回滚

- 恢复 `static/app.js` 的章节标题摘要和推进逻辑，并移除本变更卡；不触碰运行数据。
