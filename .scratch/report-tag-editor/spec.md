# 报表式标签编辑器

## 目标

- 将正式第 2 步的标签交互和排版对齐图 1 的报表式布局。
- 每个现有标签组独立支持“选择 → 确认 → 汇总/收起 → 修改”。

## 范围

- 修改 `static/index.html`、`static/app.js`、`static/styles.css`。
- 保留现有 `config/creative_tag_options.json`、`creative_tags` 字段、自动保存、条件过滤和轮播逻辑。
- 不修改后端、数据库、提示词、AI 网关或运行数据。

## 验收

- 初始无已选项的标签组显示报表；确认后只显示摘要，点击修改恢复报表。
- 展示类和叙事类都按配置分类渲染表格，选择上限和级联逻辑有效。
- `1280x720`、`390x844` 无横向溢出，控制台无 error/warn。

## 回滚

- 回滚本次前端提交，保留 `data/` 和 `chat2api/.env` 不变。
