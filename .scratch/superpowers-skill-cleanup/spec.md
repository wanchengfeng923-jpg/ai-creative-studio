# 清理旧工程技能影响

## 目标

移除仓库中由旧工程技能配置留下的专属引用和协作文档，改由当前 Superpowers 工作流维护。

## 非目标

- 不修改正式应用、AI 网关、数据库、运行数据或依赖。
- 不删除仍有项目历史价值的功能变更卡、原型或研究文档。

## 验收

- 仓库中不再出现旧工程技能的专名或安装脚本引用。
- `AGENTS.md` 不再指向旧的技能导航。
- 旧技能专属的导航文件被移除，其他项目文档引用不失效。
- `git diff --check` 通过。

## 回滚

通过 Git 恢复本次删除和文档修改；不触碰 `data/` 与 `chat2api/.env`。
