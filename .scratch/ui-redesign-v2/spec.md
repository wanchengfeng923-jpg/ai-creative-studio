# UI 重设计第二版：React 假数据原型

## 目标

验证 AI 创意工作台是否应该从传统后台表单转向以创意结果为核心的工作流，并让用户能够在真实可点击页面中比较三种交互模型。

## 范围

- 在 `frontend/` 建立隔离的 Vite + React + TypeScript + Tailwind CSS 原型。
- 使用 shadcn/ui 的组合方式实现 Button、Badge、Sheet、Command 和多选标签。
- 使用固定假项目、假创意、假评分和外部占位图片。
- 提供 `?variant=A|B|C` 三个可切换方案。
- 验证桌面 1280×720 和窄屏 390×844。

## 三个方案

- A 会话流：围绕“目标 → 三个方向 → 继续生成”组织，适合日常高频创作。
- B 素材审阅：无边框选片网格 + 右侧详情，适合快速扫图、收藏与采用。
- C 专注对比：暗色三向对比画布，适合关键批次的方向决策。

## 明确不做

- 不替换当前 `static/` 正式页面。
- 不连接项目、标签、历史、图片任务、数据库或 AI API。
- 不实现登录、权限、数据隔离、部署、备份或迁移。
- 不修改 `D:\code\bag_ai_dev`。

## 验收

- `npm run build` 成功。
- A/B/C 页面在桌面浏览器无控制台 error。
- 配置 Sheet、方向选择、采用和原型切换可操作。
- 390px 宽度无横向溢出。
