# 回滚 Runbook

1. 停止网页和网关，保留失败日志、run id、operation id 和发布 gate 输出。
2. 回退代码/registry 到上一个已验证版本；不要用旧代码覆盖新数据库文件。
3. 在新目录恢复最近一次通过校验的备份，执行只读项目/图片/上传 smoke。
4. 若必须恢复真实运行目录，先取得单独确认，核对 manifest/hash、停服务并记录覆盖范围；未确认前只保留临时恢复副本。
5. 回滚后重新运行全量 gate，并在 `progress.md` 记录失败分类、数据版本、回滚点和后续修复任务。

网络绑定、防火墙、HTTPS、服务安装、凭据和公网数据恢复不属于默认回滚权限，必须由单独变更卡授权。
