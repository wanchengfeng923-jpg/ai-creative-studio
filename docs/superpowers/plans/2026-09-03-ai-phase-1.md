# AI Phase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立 PromptRegistry、ContractRegistry、显式模型 Port、生成元数据和生产 composition-root contract harness。

**Architecture:** JSON registry 只描述版本、路径和稳定 ID；Python allowlist 提供 contract/validator/projector/caller。应用启动时一次加载并校验 registry，生成服务通过 port/fake 和 repository 加法字段保存追踪元数据。

**Tech Stack:** Python 标准库、SQLite、unittest、现有 requests HTTP adapter。

**Spec:** `.scratch/ai-phase-1/spec.md`

## Global Constraints

- 不修改正式 UI、真实数据库、图片、上传文件、凭据或网络绑定。
- registry 不动态 import、不执行 prompt 内容；路径必须位于仓库 `config/`。
- 测试只使用临时 SQLite、临时文件、fake model/image queue 和固定 clock。

**Files:** Create `src/creative_studio/contracts.py`, `src/creative_studio/prompt_registry.py`, `config/prompts/registry.json`, `config/evals/*.json` and tests.

- [ ] Implement immutable PromptSpec/GenerationPolicy and explicit allowlists.
- [ ] Load and validate six inventory entries and three production entries.

### Task 2: Ports and deterministic fakes
