## T04-002 关系结论

- schema loader 只接受三种 v1 schema；store 将 canonical、execution prompt、会话 cursor/job 等分层保存；`public_run`/`public_scheme`/`public_image_state` 从白名单重建 DTO，过滤 execution、provider cursor/job、原始响应和本地路径。
- HTTP v2 路由先将 run/scheme/attempt/queue 解析到 project，再做 owner/admin 检查；facade 直接调用不自带 HTTP caller 授权，归入 F-003 的接口边界待治理项。
- `static/ai-v2/app.js` 和正式 `static/app.js` 只消费公开 v2 字段与图片状态/URL；静态契约测试通过。真实浏览器、真实历史脏数据和多用户竞态仍未验证。
