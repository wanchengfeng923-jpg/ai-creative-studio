## 已证实结论及证据

### 1. 入口和职责边界

正式工作台由根路径 `/` 提供，`app.py._static` 对不存在的静态路径回退正式入口；`/ai-v2` 是显式隔离的辅助页面，不会回退到旧入口。静态路径解析拒绝离开 `STATIC_DIR` 的路径。辅助页面引用自身 `/ai-v2/styles.css` 与模块脚本 `/ai-v2/app.js`。

### 2. 正式前端 API 与状态流

正式 `app.js` 使用 `/api/auth/*`、`/api/projects*`、`/api/tag-options`，以及 `/api/v2/projects/{id}/generate`、queue/history/run/adoption、scheme image/frame image、image-attempts 等公开端点。脚本保持 AI 网关的 `conversation_id`、`parent_message_id`、`gateway_job_id` 等内部字段不进入浏览器公开契约；图片生成状态按方案或轮播帧独立轮询，失败可重试。

### 3. ai-v2 辅助页面契约

`static/ai-v2/app.js` 只组装公开项目、标签和 `/api/v2` 请求，使用 CSRF header；不包含网关 prompt、会话游标或内部执行字段。结果渲染仅展示 `core_idea`、`ad_copy`、`image_description`、`story`、hooks/frames 等公开字段，并将图片生成设置为显式按需动作。
