## 已证实结论及证据

### 1. 网关组合根与监听边界

`chat2api/main.py:26-78` 创建 FastAPI 应用，注册 chat、image、session 三组路由，并将生成图片目录挂载为 `/images`；`config.py:29-32` 默认 `host=127.0.0.1`、`port=8780`。健康检查和任务队列是独立只读端点。启动器 `launcher.py:32,836,879,965-974` 固定使用 `http://127.0.0.1:8780`，在 `chat2api` 工作目录启动 `main.py`，并向网页进程注入 `CREATIVE_STUDIO_AI_GATEWAY_URL`、模型、控制令牌及显式 live 开关。当前边界是同机本地网关，不是公网接口。

### 2. 对话、续聊与凭据续期

`routes_chat.py:21` 暴露 `/v1/chat/completions`，校验 `messages` 和成对的 `conversation_id`/`parent_message_id`（353-360），通过 requirements、prepare 和 Web SSE 组成一次网页会话；非流式响应返回 conversation/assistant message 标识，流式响应释放共享并发槽位。`auth_refresh.py` 在 token 临近到期时优先使用 refresh token，否则使用 session cookie，并把新凭据写回本机 `.env`；真实网关请求未运行。

### 3. 图片同步与异步任务

`routes_images.py:40-77` 同时提供兼容的同步 generations/edits 和受控制令牌保护的 `/v1/images/jobs` 提交、查询接口。异步任务通过 `ImageJobStore` 幂等复用 `request_id`，状态为 queued/generating/success/failed；网关重启时 queued/generating 会被标为 `gateway_restarted`。生成结果只保存 data URL 解码后的本地文件，并返回 `http://localhost:{port}/images/...`。`ImageGatewayAdapter` 通过 `/v1/images/jobs` 传递 conversation/parent 游标并按声明 MIME 下载，见 `src/creative_studio/ai_v2/adapters/image_gateway.py:35,107-153`。

### 4. 并发、代理和启动器职责

`task_limiter.py:12-44` 为对话和图片共享最大并发槽位，排队超时返回可重试错误；`http_client.py` 和 `web_client.py` 使用代理配置与 Chrome TLS 指纹，`launcher.py:387-400,907-922` 选择固定 ClipProxy 或本机 Clash/Mihomo 中转，不把代理凭据写入状态消息。启动器还负责健康探测、会话 Cookie 推送和网关复用；代理/启动测试覆盖了这些纯函数和请求构造，但未证明实际进程或外网链路可用。

## 推断与待确认意图

- `/v1/chat/completions` 本身没有独立业务认证；安全性依赖 `127.0.0.1` 监听和上层工作台边界。`chat2api/README.md` 要求生产配置 `CHATGPT_CONTROL_TOKEN`，但对话端点不读取该令牌，需 T04-001 与部署文档核对是否为刻意的同机信任模型。
- 图片路由的控制令牌为空时允许提交/查询，和 session 路由的“空令牌仅回环”策略并不相同；是否允许在所有部署形态下保持该差异待 T03/T04 核对。
- `routes_images.py` 以 `localhost` 组装图片 URL，而 AI v2 adapter 只允许回环/同源下载；跨进程或非默认端口部署的兼容性需在 T04-001/T04-002 复核。
- 当前 `test_ai_v2_gateway_runtime.py` 有 5 个错误，首先表现为 `AiV2PromptRegistryError: v2 prompt template hash mismatch`；直接 SHA-256 核对显示 `static-text-v1.txt`、`carousel-text-v1.txt` 与 `config/ai_v2/prompts/registry.json` 声明不一致。错误清理临时 SQLite 时还出现 Windows 文件锁；归属与修复留给 T02-006/T04，不在本轮处理。
