# ADR-0004：普通创意标签允许空选

- 状态：Accepted
- 日期：2026-09-04
- 决策范围：正式页面的展示类与叙事类标签确认规则
- Supersedes：ADR-0002 中未明确标签必选性的部分

## 背景

正式页面此前对每个标签章节统一要求至少选择一项后才能确认。这让普通创意标签成为事实上的必填项，与允许 AI 在缺少可选 brief 时补全的现有生成语义不一致。轮播开关与数量属于流程控制，不是普通创意标签，不能随本次放宽。

## 决定

- 叙事类和展示类的目标人群主选继续必填，副目标人群可为空。
- 其余普通创意标签允许空选确认，确认后在摘要中显示“未选择”，并保留修改入口。
- `visual_carousel`、`visual_carousel_count` 和 `visual_carousel_form` 继续作为必填流程控件，并维持现有条件显示和服务端校验。
- 必选事实由 `config/creative_tag_options.json` 的 `required` 字段声明，正式前端统一读取该字段。

## 影响

标签目录版本升级为 `tags-2026-09-04-v3`。本次不修改标签值、选择上限、数据库结构、提示词、AI 输出契约或轮播状态机；旧项目标签无需迁移。

## 验证

配置契约测试锁定必选组集合，前端定向测试锁定空选确认、必选提示和摘要修改入口。完整验证不调用真实 AI，不读写真实运行数据库。

## 回滚

以本次 Git 差异为边界恢复配置版本和前端统一拦截逻辑。回滚不覆盖 `data/`、图片、上传文件或 `chat2api/.env`。
