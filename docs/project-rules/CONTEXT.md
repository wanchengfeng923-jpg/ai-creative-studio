# 项目领域词汇

本文档只定义稳定的业务词汇，不记录当前版本、运行端口、审批状态、任务进度或历史结论。当前事实看 [`docs/current-state.md`](../current-state.md)，规则看 [`AGENTS.md`](../../AGENTS.md)，代码入口看 [`项目代码地图.md`](项目代码地图.md)，启动和数据操作看 [`operations.md`](operations.md)。

- **创意项目**：用户在工作台中创建并拥有的需求、定位、参考文件、生成历史和采用关系的业务容器。
- **用户**：拥有登录身份、密码和角色的工作台使用者。
- **管理员**：可以管理普通账号并访问全部项目的用户角色。
- **普通用户**：只能访问自己拥有项目的用户角色。
- **项目所有者**：对项目及其关联历史、文件、视觉项和图片资源负责的用户。
- **会话**：用户完成登录后持续一段时间的可撤销访问状态。
- **生成运行（run）**：一次 v2 文字规划请求及其持久化结果；每批有独立的运行状态和文字会话。
- **方案（scheme）**：一次生成运行下可被查看、生成图片或采用的单个创意结果。
- **图片会话（image session）**：一个方案与图片供应商之间可复用的会话游标；轮播同一方案的帧共享它。
- **图片尝试（image attempt）**：图片会话中的一次提交和对账记录；失败重试递增 attempt，不直接新建第二个会话。
- **轮播帧（frame）**：轮播方案中的有序画面步骤；后续帧必须按序推进并复用同一方案的图片会话。
- **Bootstrap 管理员**：系统首次初始化时创建的第一个管理员；初始化完成后不构成额外权限类型。
- **普通账号管理**：创建、停用、启用和重置普通用户账号，不包括删除用户或修改角色。
