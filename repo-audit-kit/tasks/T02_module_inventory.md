# T02：盘点一个模块或一条业务路径

## 本轮目标

仅完成 QUEUE 指定范围的实现盘点和证据记录，不修复程序 Bug。大型模块拆成多个可检查单元，保留跨单元接口和明确残余范围的后续核对任务。

## 前提与输入

T01 中与本任务有关的清单已完成。读本轮范围、适用规则、对应源码与测试；必要时读取依赖模块的接口片段，不加载全部既有报告。

## 执行

1. 确定本模块真实入口、导出、调用者、数据流、关键配置与测试入口。
2. 对关键流程追踪实现，记录与其他模块的接口和依赖方向。文件名相似不能证明功能重复。
3. 标明动态加载、脚本、迁移和可能的外部入口；疑似无用项只登记证据与缺口。
4. 更新范围内文件的清点、阅读、交叉核对和运行验证状态。检查强度按任务需要确定，不强制为只读盘点增加全仓测试。
5. 将确定结论和待确认问题写入本任务报告，发现编号进入台账；为新发现但本轮不覆盖的真实范围追加任务。

## 输出与完成条件

本模块职责、关键入口、相关文件、依赖边界及证据；所有范围内文件有明确审查状态，未覆盖部分有后续任务或解释。

业务代码保持本次审计范围。输出可供 T03 使用的具体源码、命令和测试证据入口；发现的程序修复事项只登记来源、影响和 deferred 后续任务，不作为当前文档整理验收依赖。完成交接后结束。
