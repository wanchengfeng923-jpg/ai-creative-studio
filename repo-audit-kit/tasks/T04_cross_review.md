# T04：跨模块复核与整理映射

## 本轮目标

检查一组跨模块关系或一组相互冲突的知识，确定后续整理范围。局部盘点完成后，此轮用于补足整体关系。

## 前提与输入

所涉及的 T02、T03 已完成，或其限制已明确且不妨碍本轮结论；队列必须显式列出全部相关 T03 依赖。读相关接口、来源和发现行；关系很多时分组执行，不在一轮汇总全部细节。

## 执行

1. 核对调用双方、共享配置、跨包职责与公共契约，检查各模块总结是否互相兼容。
2. 针对规则冲突，确认工具、版本、实际作用域和可观察的加载证据；无法判断的语义问题登记阻塞。
3. 为相关旧内容建立“保留 / 修正 / 合并 / 迁移 / 归档 / 待确认”的映射，指定目标位置、来源及验收方式。
4. 选择最少的长期维护位置；已有看板或文档可作为权威来源时复用，避免另建重复真相。
5. 据此细化 T05 和 T06 子任务的真实范围、允许修改文件、必保留约束、关联发现与必要依赖。
6. 检查剩余模块关系是否已被某个任务覆盖；没有覆盖的实际边界进入队列。

## 输出与完成条件

本组跨模块问题已核实；整理映射明确；后续修改任务可独立执行。未解决的业务冲突不能被“统一口径”掩盖。

没有跨模块内容时，依据实际清单判定不适用，不创建虚假的架构问题。T04 只做关系核对和整理映射，不实施架构变更。保存交接并结束。
