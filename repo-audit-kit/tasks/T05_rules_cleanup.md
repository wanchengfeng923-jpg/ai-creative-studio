# T05：整理一组项目规则

## 本轮目标

实际修订本任务指定的一组规则，保持有效含义与适用范围。一次只处理需要一起保持一致的规则组。

## 前提与输入

相关 T03、T04 有明确证据和整理映射；本组规则修改已在用户授权内。读取修改前规则、对应证据和当前工具的加载机制。

## 执行

1. 核对每条规则是否有效、特殊、重复、冲突或仅适用于局部任务。
2. 按映射修正错误命令与路径、合并重复、迁移局部规则和长流程。保留限制、理由、例外与适用范围。
3. 区分普通阅读链接、自动导入和路径作用域机制；不能仅拆文件就宣称减少上下文。
4. 按已知事实解决非语义冲突；业务意图或有效限制仍不明确的项保留待确认，不能擅自删去。
5. 检查新旧表达、引用与加载配置。能从当前工具确认的加载情况记录下来；需要重启或新会话的验证交给 T07。
6. 记录本轮哪些规则已变更、下一轮应重新发现哪些有效规则。不要为让当前任务通过而降低原有要求。

## 输出与完成条件

实际文件差异、规则处置记录、引用检查和待新会话验证项；没有已知的语义丢失、半迁移或断链。

完成后结束。下一轮应重新读取生效规则，不能只沿用本轮开始时的旧指令快照。
