# T06：修订文档或迁移一批进度记录

## 本轮目标

根据队列，本轮只选择一个工作单元：修订一个主题的文档，或处理一批有明确边界的历史记录。不要同时展开全部文档和完整历史。

## 前提与输入

相关 T03、T04 已给出证据和目标位置；如果依赖规则改动，相应 T05 已完成。只读相关文档、迁移映射与源证据。

## 文档修订单元

1. 修复本组已证实的命令、路径、说明和状态问题。
2. 将稳定架构概览与经常变化的实现细节分开；复用既有可信来源。
3. 合并重复内容并维护引用，保留适用版本或核验范围；不能通过只刷新日期伪装内容已核对。
4. 核对改写后的语义、链接和重要声明。

## 进度迁移单元

1. 明确本批原文范围，用事项编号和出处提取未完成任务、阻塞、有效决策及失败原因。
2. 核对状态后再迁移到当前状态、具体任务或决策记录；缺少证据时标为待验证。
3. 归档已完成的过程记录并保留来源。多轮处理同一长文件时维护原范围与新位置映射。
4. 对迁移前后未完成事项逐项对账，禁止用一段摘要替代核对；跨批重复事项按原标识合并。
5. 最后一批增加一次跨批对账，确认原文件全部范围有去向，当前状态没有互相矛盾的任务。

## 输出与完成条件

本单元实际修改、迁移关系、相关检查及未解决项。当前状态采用替换更新，不无限追加新会话流水账。

无法判定用途的内容先保留并记录，不能仅凭“太长”删除。保存交接并结束。
