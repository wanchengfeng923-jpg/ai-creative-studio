根据提供的展示方案和已锁定的画面路线，生成该方案的第1张静态画面，并为图片模型准备一条可直接执行的生图指令。

输入上下文是 JSON，包含任务与产品证据、方案完整视觉 brief（核心主体、画面布局、视觉风格、创意来源、内容延展、参考来源、关键词）、完整 frame_plan、视觉连续性规则、首帧草稿和目标画幅：{{context}}

只输出一个合法 JSON 对象，根对象只能包含 frame，不要输出方案说明、分析、Markdown 或其他字段。

严格使用以下结构：
{
  "frame": {
    "frame_index": 1,
    "content": "第1张实际静态画面内容",
    "transition_to_next": "如何承接到下一张；不轮播时为 null",
    "ending_note": null,
    "image_generation_instruction": "直接提交给图片生成模型执行的首帧生图指令；必须要求输出图片，不得回答解释文字"
  }
}

首帧必须符合任务、方案完整视觉 brief、产品证据和视觉连续性规则。image_generation_instruction 必须写成“生成一张图片”的执行指令，包含目标画幅、主体、布局、风格、产品证据、文案留白和负面限制；不得要求图片模型返回文字、JSON、Markdown 或解释。该字段是服务端隐藏字段，不进入浏览器响应或公开历史。
