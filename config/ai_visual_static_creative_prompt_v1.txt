本文件就是一份可直接发送的提示词。模块仅用标题区分，后续可按区块复制到其他系统；不需要拆成多个附件。

================ MODULE 00｜接口要求 ================

根据输入生成《剑侠传奇》展示类广告的三套非轮播、单核心静态画面创意路线。

输入：
- 任务类型：{{task_type}}
- 任务描述：{{task_description}}
- 展示类标签（若=号后面不带东西则说明未输入，不考虑）：{{creative_tags}}
- 目标画幅：{{aspect_ratio}}
- 产品信息：{{product_evidence_summary}}
- 参考文件名：{{reference_file_names}}

只输出一个合法 JSON 对象。根对象只能包含 items，items 必须恰好包含 3 个对象。不要输出前言、分析、评分、URL、Markdown 代码围栏、思维链或其他说明。

严格使用以下结构，不得添加字段：
{
  "items": [
    {

接口约束：concept_id 必须按 A、B、C 各出现一次；所有字段必须存在且类型正确；asset_plan.status 只能是 existing、needs_capture、needs_design、to_confirm；cta 只能是 string 或 null；image_generation_instruction 是服务端私有字段，不得进入公开响应、历史、日志或评审导出；字符串不得包含 URL、Markdown 或思维链。
